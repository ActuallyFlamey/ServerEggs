# Privacy Policy for Server Eggs

*(**Disclaimer**: This Privacy Policy was generated using **Google Gemini 3.1 Pro**, because I don't exactly have the resources to ask a legal professional about some silly bot.)*

**Last Updated:** August 6, 2026

This Privacy Policy explains how Server Eggs ("the Bot", "we", "us", or "our") collects, uses, and shares data when you add the Bot to your Discord server or use its features. By using Server Eggs, you agree to the collection and use of information in accordance with this policy.

## 1. Information We Collect
To provide its core functionality, the Bot collects and stores the following information:
*   **User Data:** Your Discord User ID, username, and display name.
*   **Server (Guild) Data:** Server IDs, Server names, and automatically generated server invite links.
*   **User-Generated Content ("Eggs"):** Text, images, or other attachments you submit when creating an Egg. 

## 2. How We Use Your Information
We use the collected data exclusively to operate the Bot and provide its features:
*   **Creating and Sharing Eggs:** To display the Eggs you create to other users across different Discord servers.
*   **Attribution:** To properly credit you as the creator of an Egg by displaying your username, display name, and a link to your Discord profile.
*   **Server Discovery:** To allow users to join the server where an Egg was created via the stored invite link.
*   **Analytics and Maintenance:** The developers have access to a list of servers (names and IDs) the Bot is currently in to monitor bot health, scaling, and general usage. 

## 3. Data Visibility and Sharing
**Server Eggs is a cross-server application.** When you create an Egg, the content of that Egg, your profile information, and the origin server's name and invite link become **globally visible** to any user on any server where the Bot is installed. 
*   We do not sell your data to third parties.
*   Data is only shared within the Discord ecosystem through the Bot's interface.

## 4. User and Server Controls
*   **Server Privacy:** Server administrators can opt out of the public invite system. By running `/config privacy private:True`, the Bot will no longer display the invite button allowing external users to join your server via an Egg.
*   **Content Restrictions (NSFW):** Eggs marked as NSFW (which can only be created in age-restricted channels) will strictly only be retrievable in other designated NSFW channels.

## 5. Data Retention and Deletion
Data is stored indefinitely to ensure Eggs remain accessible. If you wish to have your data, your Eggs, or your server's data removed from our database, please contact the developer via email at [flamey@hexa.blue](mailto:flamey@hexa.blue). 

## 6. Open Source
The source code for Server Eggs is publicly available under the GPL-3.0 License on GitHub. While the code is public, the database containing user and server information is strictly private and secured by the developers.
